# 🧮 Calculator Web App

A modern and responsive Calculator built using HTML, CSS, and JavaScript.  
It performs basic arithmetic operations with a clean and interactive user interface.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📱 Responsive Design
- ⚡ Fast & Interactive UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

---

## 🚀 How to Run

1. Download or clone this repository
2. Open the project folder
3. Double-click on `index.html`

---

## 📂 Project Structure

Calculator/
├── index.html
├── style.css
├── script.js
└── README.md

This project was created to practice JavaScript DOM manipulation, event handling, and responsive web design.
